# Adding a new **ProgressiBook** to the "Example Gallery"

```{eval-rst}

.. note::
       The "Example Gallery" is a section of the `ProgressiVis documentation <https://progressivis.readthedocs.io/en/latest/gallery.html>`_ (i.e. not `ipyprogressivis`)
```

The documentation in the 'doc' directory of the `progressivis` repository represents the **ProgressiVis user documentation** covers both the progressivis and ipyprogressivis packages (since the current documentation is about dev). Most sections are managed solely through the features provided by the Sphinx tool, but the "Example Gallery" section requires special handling.

To add or replace a `ProgressiBook` (let's call it `MyProgressiBook.ipynb`) in the example gallery, follow these steps:

1. Enable the `progressivis` and `ipyprogressivis` development environments

2. In the root directory of the `ipyprogressivis` repository, run:

    ```shell
    python scripts/nb_to_doc_html.py -p notebooks/MyProgressiBook.ipynb -o notebooks/
    ```

    ```{eval-rst}

    .. note::
	   More information about this script :ref:`here <nb-to-doc-html>`

    ```

3. Copy the html file generated above (notebooks/MyProgressiBook.html) into the doc repository and add it to git:

    ```shell
    cp notebooks/MyProgressiBook.html /path/to/your/progressivis/doc/_static/
    cd /path/to/your/progressivis/
    git add doc/_static/MyProgressiBook.html
    ```

4. Copy the last bundle javascript generated by the ipyprogressivis build process to the `doc/_static/` dir and add it to git. Do the same for the underlying license file:

    ```shell
    cd /path/to/your/progressivis/
    cp /path/to/your/ipyprogressivis/ipyprogressivis/nbextension/index.js doc/_static/jupyter-progressivis.js
    cp /path/to/your/ipyprogressivis/ipyprogressivis/nbextension/index.js.LICENSE.txt doc/_static/jupyter-progressivis.js.LICENSE.txt

    git add doc/_static/jupyter-progressivis.js
    git add doc/_static/jupyter-progressivis.js.LICENSE.txt
    ```

5. Commit, push
